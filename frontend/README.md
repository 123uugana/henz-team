# Henz Hurag Frontend

This folder is reserved for the frontend application.

## How to work here

```bash
git clone https://github.com/123uugana/henz-team.git
cd henz-team
git checkout -b frontend
cd frontend
```

Put the frontend app code in this folder, then commit and push:

```bash
git add frontend
git commit -m "Add frontend app"
git push -u origin frontend
```

Backend code lives in `../backend`.
